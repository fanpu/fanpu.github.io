# Poker trainer M1: core — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pure, node-tested poker core (`games/poker/js/core/`): cards, evaluator, preflop ranges, positions, event-sourced engine, range reads, equity, analysis, bots and coach.

**Architecture:** Plain ES modules with no DOM, no three.js and no `Math.random`; every random choice takes an injected `rng`. The engine is rewritten events-first; evaluator, range model, analysis and coach heuristics are ported from the old single file (`git show 5a64bf9c:games/poker/index.html`, called OLD below) and adapted to the new state shape. All state is JSON-serialisable so it can cross into a Web Worker in M3.

**Tech Stack:** JavaScript ES2022 modules, `node --test` (node 20), no dependencies.

**Spec:** `games/poker/_docs/2026-09-19-poker-trainer-3d-design.md`. This is plan 1 of 6, one per spec milestone; later plans are written when their milestone starts.

## Global Constraints

- `core/` imports nothing outside `core/` and never touches `Math.random`, `window` or `document`.
- `rng` is always a function returning a float in `[0, 1)`.
- Cards are `{ r, s }`: `r` 2..14 (14 = ace), `s` 0..3 indexing `['♠','♥','♦','♣']`.
- Streets: 0 preflop, 1 flop, 2 turn, 3 river, 4 hand complete.
- Chips are integers. `BB = 2`, `SB = 1`, `BUYIN = 200`. Seat 0 is the hero.
- All state objects are JSON-serialisable (no functions, Sets, Maps or class instances on state).
- Files are formatted with the repo `.prettierrc` (print width 150).
- Tests live in `games/poker/_tests/*.test.mjs` and run with `cd games/poker && npm test`.
- Commit after every task, message prefix `poker core:`.

## Deviations from the spec's file list (spec updated to match)

- `core/positions.js` added: position names and position-dependent percentages, used by bots, coach and lessons.
- `core/reads.js` added: what an observer infers from actions (VPIP/PFR, assumed range, story). OLD did this inside `act()`; it is a consumer of engine events, not a rule of poker.
- `replay` takes a hand-start snapshot rather than `(config, seed)`: stacks carry between hands, so a hand is reproducible from its own starting state.

```js
export function makeRng(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
export const randInt = (rng, n) => Math.floor(rng() * n);
```

### Task 4: Event-sourced engine

**Files:** Create `js/core/engine.js`; Test `_tests/engine.test.mjs`, `_tests/engine.property.test.mjs`

**Interfaces — Produces:**

```
BB=2, SB=1, BUYIN=200, STREET_NAMES=['preflop','flop','turn','river']
createGame({ n, names? }) -> state
  state = { config:{n,sb,bb,buyin}, handNo, dealer, street, board, deck, toAct, currentBet, minRaise,
            raises, lastAggressor, handOver, result, actions:[],
            players:[{ id, name, stack, cards, bet, invested, folded, allIn, needAct, raiseLocked, startStack }] }
startHand(state, rng) -> events            // rotates button, rebuys busted players, posts, deals
legalActions(state) -> null | { seat, toCall, canCheck, canRaise, minTo, maxTo, pot }
clampRaise(legal, to) -> int               // rounds, clamps to [minTo, maxTo]
apply(state, action) -> events             // action = { seat, type:'fold'|'check'|'call'|'raise', to? }; throws on illegal
pot(state), alive(state), actors(state)
snapshot(state) -> deep copy               // taken right after startHand
replay(snap, actions, upto = actions.length) -> { state, events }
```

Events (plain objects, `type` field):
`handStart{handNo,dealer,sbSeat,bbSeat,rebuys:[seat]}`, `post{seat,amount,kind}`, `deal{hands:{[seat]:[c,c]}}`,
`action{seat,kind:'fold'|'check'|'call'|'bet'|'raise',added,to,allIn,street,toCallBefore,potBefore,currentBetBefore,raisesBefore,boardLen,pos}`,
`refund{seat,amount}`, `street{street,cards,pot}`, `showdown{hands:[{seat,cards,score,desc,best5}]}`,
`award{potIndex,amount,seats,shares:{[seat]:int},contested}`, `handEnd{net:{[seat]:int},showdown:boolean}`.

Rules that differ from OLD (OLD was lenient; these are the real rules):
- `check` facing a bet and `call` with nothing to call throw. `fold` is always legal.
- `raise` requires `minTo <= to <= maxTo`, except `to === maxTo` (all-in) is always allowed when `canRaise`.
- A short all-in (increment < `minRaise`) raises `currentBet` and makes players who already acted `needAct` again, but sets their `raiseLocked`, so `legalActions.canRaise` is false for them; `minRaise` does not change. A full raise clears every `raiseLocked`.
- When a betting round closes or the hand ends by folds, the uncalled part of the top bet is returned with a `refund` event before any `street`, `showdown` or `award`.
- Side pots are built from `invested` levels among all players, eligible = not folded and invested >= level. Odd chips go one at a time to winners in seat order starting left of the button.
- Heads-up: the button posts the small blind and acts first preflop, last postflop.
- After `apply`, the engine advances itself: next actor, or deals streets (running the board out when at most one player can act), or showdown. `toAct` is -1 when the hand is over.
